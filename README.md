# ClipboardManager

Clipboard history for Windows, macOS and Linux (including Ubuntu/GNOME on Wayland), like Ditto.

- Saves every text and image you copy.
- Press `Ctrl+Alt+V`, search, press Enter to copy an item back.
- Pinned items stay forever. The rest are removed after 3 days (configurable).

In development. Setup and build: `docs/setup.md`. Design: `docs/specs/2026-09-30-clipboard-manager-design.md`.
